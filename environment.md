# Environment Variables

This document describes the environment variables used in the project.

- `NEXT_PUBLIC_API_BASE_URL`: The base URL for the API. It can be set to the production URL (`https://backend-autumn-leaf-7356.fly.dev/api/v1`) or the local development URL (`http://localhost/api/v1`).

- `AUTH0_SECRET`: The secret key used by Auth0 for signing tokens.

- `AUTH0_BASE_URL`: The base URL of the application for Auth0.

- `AUTH0_ISSUER_BASE_URL`: The Auth0 issuer base URL.

- `AUTH0_AUDIENCE`: The audience identifier for Auth0.

- `AUTH0_CLIENT_ID`: The client ID for Auth0.

- `AUTH0_CLIENT_SECRET`: The client secret for Auth0.

- `AUTH0_SESSION_AUTO_SAVE`: A boolean value indicating whether to automatically save sessions.

- `NEXT_PUBLIC_PAYPAL_CLIENT_ID`: The client ID for PayPal integration.

- `NEXT_PUBLIC_PAYPAL_PLAN_ID`: The plan ID for PayPal subscriptions.
